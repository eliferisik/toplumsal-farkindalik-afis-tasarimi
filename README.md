# Toplumsal Farkındalık Afiş Tasarımı
Kadına yönelik şiddet ve kadın cinayetlerine dikkat çekmek, toplumsal farkındalık oluşturmak amacıyla hazırlanan afiş tasarımı.
# Tasarım
Afiş tasarımında tipografi, görsel anlatım, renk kullanımı ve kompozisyon unsurlarından yararlanılmıştır.
